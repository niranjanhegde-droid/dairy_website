# 🐄 Dairy Website

A responsive website designed for a traditional dairy brand, showcasing products, the manufacturing process, and contact details — all with a consistent and clean design.

## 🌐 Live Preview

[View Website](https://niranjanhegde-droid.github.io/dairy_website/)

## 📁 Project Structure

- `index.html` – Homepage
- `product.html` – Product showcase
- `gallery.html` – Image gallery
- `contact.html` – Contact form
- `css/`, `scss/`, `js/`, `img/`, `lib/` – Assets and supporting files

## 🛠️ Technologies Used

- HTML5
- CSS3 / SCSS
- JavaScript
- Responsive design (mobile-friendly)
